# התקנת בית 9

נדרשת גרסת Home Assistant 2026.5 ומעלה לבחירה מתוך מסך הדשבורדים הקהילתיים.

1. פתחו את HACS ובחרו **Custom repositories** בתפריט.
2. הוסיפו את המאגר **yahavzarfati/bayit-9** בקטגוריה **Dashboard** והורידו אותו.
3. רעננו את Home Assistant בדפדפן. באפליקציה, סגרו ופתחו מחדש את תצוגת הדשבורד.
4. פתחו **הגדרות ← דשבורדים ← הוספת דשבורד ← דשבורדים קהילתיים** ובחרו **Bayit 9**.

מכשירים מסודרים לפי החדרים שהוגדרו ב־Home Assistant. מכשירים ללא שיוך לחדר יופיעו תחת ״ללא חדר״. לחצו על סמל העיפרון של Home Assistant בדשבורד כדי לבחור חדרים, לסדר את הקיצורים שלהם ולהגדיר בקר לדוד או לתנור. את הרקע וצורת הכפתורים אפשר לשנות גם מכפתור ״מראה״ בתוך בית 9.

אם בחרתם להתקין במפורש גרסת בדיקה, הפעילו **Show beta versions** בתפריט של Bayit 9 ב־HACS לפני בחירת הגרסה.
