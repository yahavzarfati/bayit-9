# התקנת בית 9

נדרשת גרסת Home Assistant 2026.5 ומעלה לבחירה מתוך מסך הדשבורדים הקהילתיים.

- **Home Assistant 2026.11 ומעלה.** פתחו **הגדרות ← Marketplace ← Add from link**, חברו את GitHub אם תתבקשו והזינו `yahavzarfati/bayit-9`. פתחו את המאגר ובחרו **Install**. [מדריך Marketplace](https://www.home-assistant.io/integrations/marketplace/#custom-repositories)
- **Home Assistant 2026.5 עד 2026.10 עם HACS.** בתפריט של HACS בחרו **Custom repositories**, הוסיפו `yahavzarfati/bayit-9` בקטגוריה **Dashboard** והורידו אותו. אם בחרתם בגרסת בדיקה, הפעילו **Show beta versions** בתפריט Bayit 9.

אחרי ההורדה, רעננו את Home Assistant. באפליקציה, סגרו ופתחו מחדש את תצוגת הדשבורד. פתחו **הגדרות ← דשבורדים ← הוספת דשבורד ← דשבורדים קהילתיים** ובחרו **Bayit 9**.

מכשירים מסודרים לפי החדרים שהוגדרו ב־Home Assistant. מכשירים ללא שיוך לחדר יופיעו תחת ״ללא חדר״. לחצו על סמל העיפרון של Home Assistant בדשבורד כדי לבחור חדרים, לסדר את הקיצורים שלהם ולהגדיר בקר לדוד או לתנור. את הרקע וצורת הכפתורים אפשר לשנות גם מכפתור ״מראה״ בתוך בית 9.
