# התקנת בית 9

נדרשת גרסת Home Assistant 2026.5 ומעלה לבחירה מתוך מסך הדשבורדים הקהילתיים.

- **Home Assistant 2026.11 ומעלה.** פתחו **הגדרות ← Marketplace ← Add from link**, חברו את GitHub אם תתבקשו והזינו `yahavzarfati/bayit-9`. פתחו את המאגר ובחרו **Install**. [מדריך Marketplace](https://www.home-assistant.io/integrations/marketplace/#custom-repositories)
- **Home Assistant 2026.5 עד 2026.10 עם HACS.** בתפריט של HACS בחרו **Custom repositories**, הוסיפו `yahavzarfati/bayit-9` בקטגוריה **Dashboard** והורידו אותו. אם בחרתם בגרסת בדיקה, הפעילו **Show beta versions** בתפריט Bayit 9.

אחרי ההורדה, רעננו את Home Assistant. באפליקציה, סגרו ופתחו מחדש את תצוגת הדשבורד. פתחו **הגדרות ← דשבורדים ← הוספת דשבורד ← דשבורדים קהילתיים** ובחרו **Bayit 9**.

בית 9 מתחיל מהחדרים והשיוכים שהוגדרו ב־Home Assistant. כמנהלי המערכת, פתחו את גלגל השיניים ובחרו **עריכת הדשבורד**. תחת **ניהול חדרים** אפשר לשנות סדר, להסתיר חדר ולהחזיר אותו. על כל כרטיס חדר, **ניהול מכשירים** מאפשר לשנות את סדר הפקדים ולהסתיר או להחזיר אותם בחדר הזה. במצב אוטומטי הבית ממשיך לקלוט חדרים ומכשירים חדשים. בחרו **שמירת הדשבורד** כדי להחיל את השינויים בכל המכשירים.

כפתור זכוכית המגדלת בכותרת ההגדרות פותח חיפוש לפי שם, חדר או סוג מכשיר. אפשר לסמן חדרים ומכשירים כמועדפים בדפדפן הנוכחי. ב־**ניהול חדרים ← פריסות חדר** אפשר לבחור פריסה מוכנה או להשתמש בקבוצות מחדר אחר ולשייך אותן למכשירים של החדר הנבחר.

בחדרים אוטומטיים אפשר לבצע פעולות קבוצתיות בתאורה ובתריסים מתאימים. הפעולה מציגה את מספר היעדים ומבקשת אישור. אפשר להציג או להסתיר את הפקדים לקבוצה בהגדרות החדר.

ב־**התאמת הבית ← מראה ← תמונות משותפות** אפשר להוסיף רקעים מקבצים ש־Home Assistant מגיש ב־‎`/local/`‎. בחרו **שמירת הדשבורד** כדי להציג את התמונות בגלריה בכל מכשיר. תמונה שנוספה דרך **התמונה שלי** נשארת בדפדפן הנוכחי.

בבחירה ידנית, חדר שבחרתם מוצג גם כשהוא ריק. אפשר להסתיר את כל החדרים או לחזור לבחירה אוטומטית. הצגת מכשירים שלא שויכו לחדר נקבעת בנפרד.

במסך ההתאמה אפשר לבחור גם עד שישה קיצורים לכל חדר ומיפוי לטיימר של דוד או תנור. את הרקע וצורת הכפתורים אפשר לשנות מכפתור המראה בתוך בית 9.
