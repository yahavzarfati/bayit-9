# Bayit 9 and Dwains Dashboard Next

The reference is Dwains Dashboard Next [v1.15.1](https://github.com/dwainscheeren/dwains-dashboard-next/tree/92624996ede2c619608be13120b9f32186e76222). The review compares the installed products and the pinned source. Bayit 9 implements its own interfaces over Home Assistant's room, device and entity registries.

The native acceptance driver exercises two fresh Home Assistant Core 2026.11.3 profiles. The rental flat creates Bayit 9 through the Community dashboards picker and checks a grouped light action. The Hebrew garden house checks the header layout, two floors and a grouped cover action that leaves the garage outside the group. Both move a demo device into a room after saving its configuration and check live discovery, Finder aliases and restoration. [Acceptance commands](acceptance.md)

Home Assistant's Lovelace save API does not provide a compare-and-swap revision. The save queue coordinates editors on a shared connection and rebases onto the latest readable configuration. A simultaneous write from a different client can still race a save.
